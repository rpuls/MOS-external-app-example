# Example Notes — technical reference

Single-service Node application used as the reference MOS external app package.

## Services

| Service | Dockerfile | Internal port | Base image |
| --- | --- | --- | --- |
| `notes` | `Dockerfile` | 8080 | `node:22-alpine`, pinned by digest |

## Environment variables

| Variable | Source | Purpose |
| --- | --- | --- |
| `PORT` | literal `8080` | Listen port; must match `internalPort`. |
| `BOARD_TITLE` | `${config.boardTitle}` | Heading shown on the page. |
| `ADMIN_TOKEN` | `${secret.adminToken}` | Required by `POST /api/reset`. Generated by MOS at install. |
| `PUBLIC_URL` | `${app.publicUrl}` | Resolved by the app agent at start. Not used for anything here beyond showing that the template resolves. |

## Volumes

| Volume | Mount | Contents |
| --- | --- | --- |
| `notes-data` | `/data` | `notes.json`, written atomically via a temporary file and rename. |

Named volume only. External packages may not use bind mounts or host paths.

## Endpoints

| Method | Path | Notes |
| --- | --- | --- |
| `GET` | `/` | HTML page listing notes. |
| `POST` | `/notes` | Form submission; redirects to `/`. |
| `GET` | `/api/notes` | JSON list. |
| `POST` | `/api/reset` | Erases all notes. Requires `X-Admin-Token`. |
| `GET` | `/healthz` | Health endpoint. |

## Health

`health.url` is `http://notes:8080/healthz`.

Only two parts of that URL are used by MOS: the hostname selects **which declared service** to probe, and the path is appended to the probe target. The port is ignored — MOS probes the service on a loopback port it derives itself. Two consequences worth knowing when writing your own package:

- The hostname must exactly match a service id in `resources.services`. A typo does not raise an error; MOS silently falls back to probing `routes[0].service` instead.
- The probed service must appear in `routes`, otherwise no port is published and the probe has nothing to connect to.

## Limits

- Note text is truncated to 500 characters; the board keeps the newest 200 notes.
- Request bodies over 64 KiB are refused.

## Local run (without MOS)

```sh
docker build -t example-notes .mos
docker run --rm -p 8080:8080 \
  -e BOARD_TITLE="Local test" \
  -e ADMIN_TOKEN="local-token" \
  -v example-notes-data:/data \
  example-notes
```
